# حينما يتحول الملكوت لكلام مكتوب

موقع روايات عربي ثابت مناسب لـ GitHub Pages.

## التشغيل
ارفع **محتويات** هذا المجلد إلى جذر مستودع GitHub، ثم Settings → Pages → Deploy from a branch → main / root.

## نشر الفصول
ضع النص الكامل لكل فصل في `chapters/zat-1.txt` إلى `zat-9.txt` و`chapters/kader-1.txt` إلى `kader-3.txt`. النصوص غير مرفقة ولم تُخترع. ملف نصي UTF-8 لكل فصل. تأكد من نشر النص قبل تجربة القراءة الصوتية أو التنزيل.

## التعليقات والتقييمات الحقيقية
1. أنشئ مشروع Supabase.
2. نفذ ملف `supabase.sql` من SQL Editor.
3. ضع Project URL و **publishable / anon key فقط** في `config.js`. لا تضع service_role أو secret key في موقع عام.
4. انشر الملفات مجددًا. ستظهر المشاركات المشتركة للقراء.

**تنبيه أمني مهم:** النشر باسم زائر لا يتحقق من الهوية؛ ويمكن تكرار التقييمات وإغراق التعليقات. قبل فتحه للجمهور يُنصح بإضافة CAPTCHA، وحدود معدل الطلبات، ومراجعة التعليقات عبر وظيفة خادمية/Edge Function، ومنع التقييم المتكرر بمعرّف موثوق. السياسات الحالية نموذج أولي مفتوح وليست نظامًا مقاومًا للسبام. لا يوجد نظام إدارة وحذف التعليقات من الواجهة بعد.

## خصائص القارئ
- حفظ موضع الفقرة والتقدم والعلامة المرجعية محليًا لكل فصل على نفس المتصفح.
- التحكم في حجم الخط والمظهر.
- القراءة الصوتية عبر أصوات المتصفح العربية إن توفرت (قد تختلف الجودة والاتاحة حسب الجهاز).
- زر PDF يفتح نافذة طباعة، اختر Save as PDF؛ لا يولّد ملف PDF مباشرة.
- زر EPUB يولّد ملفًا للفصل المنشور فقط باستخدام JSZip من CDN؛ يحتاج إنترنت لتحميل المكتبة.
- لا تتم مزامنة تقدم القراءة بين الأجهزة.
