الملكوت المكتوب — حزمة نظام النشر الذكي (نسخة تجريبية)

1. ارفع محتويات الحزمة (وليس ملف ZIP نفسه) إلى جذر مستودع qkplay/malakut-novels مع الحفاظ على المسارات والمجلدات.
2. لا تحذف ملفات HTML القديمة ولا تستبدل index.html الحالي.
3. افتح GitHub > Settings > Pages > Build and deployment > Source واختر GitHub Actions (هذه الخطوة ضرورية لتشغيل النشر الجديد).
4. افتح Actions > Publish smart library > Run workflow إن لم يبدأ تلقائيًا.
5. راجع النتيجة على رابط موقعك بعد نجاح النشر.
6. لرفع رواية جديدة، ارفع HTML باسم الرواية، وللفصول استخدم الصيغة: اسم الرواية-الفصل الأول.html وهكذا.
7. الصور الخمس موجودة داخل assets/covers. ربطها آليًا يعتمد على اسم الرواية.
8. روابط التريلرات تضاف إلى القاموس TRAILERS في tools/build.py عند توفرها؛ الزر لا يظهر بدون رابط حقيقي.
9. الأعداد تحسب من الملفات المنشورة لا من عدد الزيارات. عدد الزيارات الفعلي يحتاج خدمة منفصلة.
10. الأدوات تحفظ موضع التمرير في متصفح الزائر فقط. استخدم النسخة التجريبية أولًا، فقد تختلف بنية HTML للروايات.
11. عند فشل النشر يمكنك الرجوع إلى Settings > Pages > Source > Deploy from a branch، والملفات الأصلية ستظل موجودة.

ملاحظة: لا يمكن استنتاج عنوان الرواية والفصول بدقة مطلقة من أي اسم عشوائي؛ الالتزام بتسمية الفصول هو أفضل طريقة للاكتشاف التلقائي.
